ILA Compass — Análisis reproducible del modelo de riesgo¶

Este notebook documenta de forma reproducible el desarrollo de un modelo clínico-proteómico para estimar el riesgo de progresión en pacientes con anomalías pulmonares intersticiales (ILA).

El flujo completo incluye definición de cohorte, control de calidad, preprocesado, modelado, validación cruzada, evaluación, estratificación de riesgo e interpretación del modelo.

Principio de diseño: priorizar una firma pequeña, interpretable y evaluada sin fuga de información.

1. Pregunta clínica y cohorte¶

La pregunta no es “¿está sano o enfermo?”, sino:

Dado que el paciente ya presenta ILA, ¿qué probabilidad tiene de progresar?

Por eso excluimos controles sanos y pacientes con EPID ya establecida del análisis predictivo principal.

3. Variables finales y prevención de data leakage¶

Variables clínicas basales¶

  • edad, sexo, IMC
  • tabaquismo acumulado
  • FVC basal, DLCO basal
  • patrón de TC

Firma proteómica final¶

  • SFTPB — daño/biología del epitelio alveolar
  • GDF15 — estrés celular
  • MMP7 — remodelado de matriz/fibrosis
  • SFTPD — surfactante y daño pulmonar

Variables que NO entran¶

FVC de visitas posteriores, delta FVC, tiempos de seguimiento u otra información posterior al momento basal.

Si una variable no estaría disponible cuando queremos hacer la predicción, no puede entrar en el modelo.

4. Pipeline de preprocesado + modelo¶

Todo el preprocesado está dentro del Pipeline, por lo que en cada fold se aprende únicamente con el training set:

  1. Numéricas ausentes → mediana del training fold.
  2. Numéricas → StandardScaler.
  3. Categóricas ausentes → categoría más frecuente del training fold.
  4. Sexo y TC → OneHotEncoder.
  5. Modelo → regresión logística regularizada L2.

La regresión logística genera un score y lo transforma en probabilidad:

[ S = eta_0 + \sum_i eta_i x_i ]

[ P( ext{progresión}) = rac{1}{1+e^{-S}} ]

Los coeficientes no se asignan manualmente: se aprenden a partir de los pacientes de entrenamiento.

In [7]:
def build_pipeline(numeric_columns):
    preprocess = ColumnTransformer([
        (
            "num",
            Pipeline([
                ("imputer", SimpleImputer(strategy="median")),
                ("scaler", StandardScaler()),
            ]),
            numeric_columns,
        ),
        (
            "cat",
            Pipeline([
                ("imputer", SimpleImputer(strategy="most_frequent")),
                ("onehot", OneHotEncoder(drop="first", handle_unknown="ignore")),
            ]),
            clinical_categorical,
        ),
    ])

    return Pipeline([
        ("preprocess", preprocess),
        ("classifier", LogisticRegression(
            C=1.0,
            solver="liblinear",
            max_iter=5000,
        )),
    ])

cv = StratifiedKFold(
    n_splits=5,
    shuffle=True,
    random_state=RANDOM_STATE,
)

print("Pipeline preparado: imputación → escalado/one-hot → regresión logística L2")

Pipeline preparado: imputación → escalado/one-hot → regresión logística L2

5. Validación cruzada estratificada de 5 folds¶

En cada iteración:

  • 4 folds entrenan el modelo.
  • 1 fold se reserva completamente para test.
  • Se repite hasta que cada paciente ha sido test una vez.

El resultado son 650 predicciones out-of-fold (OOF): cada paciente recibe una probabilidad de un modelo que no fue entrenado con él.

Esta es la base de todas las métricas que defendemos ante el jurado.

In [8]:

6. Rendimiento del modelo final¶

Usamos tres métricas porque responden a preguntas diferentes:

  • ROC-AUC: capacidad de ordenar/separar progresores y no progresores.
  • Average Precision: relación precision–recall, especialmente informativa para la clase positiva.
  • Brier Score: error de las probabilidades; menor es mejor.

7. De una probabilidad a tres grupos de riesgo¶

Los umbrales se derivan de las predicciones OOF:

  • Bajo riesgo: buscamos sensibilidad ≥95% y, entre esos puntos, máxima especificidad.
  • Alto riesgo: buscamos especificidad ≥90% y, entre esos puntos, máxima sensibilidad.
  • Entre ambos queda el grupo intermedio.
In [12]:
fpr, tpr, thresholds = roc_curve(y, final_pred)
specificity = 1 - fpr

low_candidates = np.where(tpr >= 0.95)[0]
low_idx = low_candidates[np.argmin(fpr[low_candidates])]
low_cutoff = thresholds[low_idx]

high_candidates = np.where(specificity >= 0.90)[0]
high_idx = high_candidates[np.argmax(tpr[high_candidates])]
high_cutoff = thresholds[high_idx]

risk_group = np.where(
    final_pred < low_cutoff,
    "Bajo",
    np.where(final_pred >= high_cutoff, "Alto", "Intermedio")
)

risk_rows = []
for group in ["Bajo", "Intermedio", "Alto"]:
    mask = risk_group == group
    n = int(mask.sum())
    prog = int(y[mask].sum())
    risk_rows.append({
        "Grupo": group,
        "n": n,
        "Progresores": prog,
        "Progresión observada": prog/n,
    })

risk_df = pd.DataFrame(risk_rows)

print(f"Cutoff bajo: {low_cutoff:.3f} | sensibilidad={tpr[low_idx]:.3f} | especificidad={specificity[low_idx]:.3f}")
print(f"Cutoff alto: {high_cutoff:.3f} | sensibilidad={tpr[high_idx]:.3f} | especificidad={specificity[high_idx]:.3f}")
display(risk_df.style.format({"Progresión observada": "{:.1%}"}))

Interpretación de los coeficientes¶

  • Coeficiente positivo → aumenta el score de riesgo.
  • Coeficiente negativo → reduce el score de riesgo.
  • En variables numéricas, el coeficiente actúa sobre valores estandarizados.
  • Una asociación predictiva no implica causalidad.

10. De modelo a producto: ILA Compass¶

La calculadora traduce el modelo a una interfaz comprensible:

  • probabilidad individual de progresión,
  • semáforo bajo / intermedio / alto,
  • factores que aumentan o reducen el score,
  • resumen interpretativo,
  • siguientes pasos orientativos para revisión clínica,
  • curva ROC y métricas globales del modelo,
  • exportación del informe.

Importante: es un prototipo de investigación y apoyo a la interpretación, no un dispositivo médico validado.

11. Limitaciones y siguientes pasos¶

Limitaciones¶

  • Rendimiento basado en validación interna de una única cohorte.
  • Biomarcadores y umbrales de riesgo derivados en la misma cohorte de desarrollo.

Siguiente paso¶

  • Validación externa en una cohorte independiente.
  • Evaluación de calibración y estabilidad de los umbrales.
  • Validación prospectiva multicéntrica antes de cualquier uso clínico.
